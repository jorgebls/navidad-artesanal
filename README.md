

# 🎄 Navidad Artesanal

Aplicación web para la venta de artículos navideños artesanales (bolitas, moños, cajas, tambores).  
Proyecto universitario desarrollado en **Angular**.

---

##  Requisitos previos (Windows)

Antes de clonar el repositorio, asegúrate de tener instalado:

1. [Git](https://git-scm.com/download/win) → para clonar el repositorio.  
2. [Node.js](https://nodejs.org/en/) (versión recomendada: **20.x LTS**)  
   - Incluye `npm`, que usaremos para instalar dependencias.  
3. [Angular CLI](https://angular.dev/tools/cli) (última versión) → instalar con:
   ```bash
   npm install -g @angular/cli


⸻

📥 Clonar el repositorio

En la carpeta donde quieras guardar el proyecto:

git clone https://github.com/tu-usuario/navidad-artesanal.git
cd navidad-artesanal/web

(reemplaza tu-usuario con tu usuario real de GitHub)

⸻

📦 Instalar dependencias

Entra a la carpeta web (donde está package.json) y ejecuta:

npm install

Esto descargará todas las librerías necesarias (Angular, Material, etc.).

⸻

▶️ Correr el proyecto en modo desarrollo

Dentro de la carpeta web:

npm start

Esto inicia el servidor de desarrollo.
Por defecto estará disponible en:

👉 http://localhost:4200
